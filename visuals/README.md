# 解释性说明

图像有局部示意、比较图和完整页面，各自只解释指定问题。不能把某张图的稀疏程度、色系或画幅当作所有作品的要求。判断一套作品应有的气质与饱满程度，请结合用户范例和 [设计库](../design-library/README.md)。
