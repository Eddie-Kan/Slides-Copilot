# 检查与改稿

审阅是判断当前页面能否完成表达任务。先看内容是否成立，再看视觉是否准确传达；优先修改影响最大的问题。

## 单页怎么看

缩到整页时，能否迅速看出重点、阅读方向和信息分组？回到实际展示尺寸，标题和正文是否清楚、重要证据是否足够大？放大后，文字是否准确，边缘、光影和材质是否自然？这三个观察尺度分别回答不同问题。

逐项核对准确文案、数据与单位，再检查图表比例、图文对应、品牌及产品外形。视觉上看可见字形的对齐、组内与组间间距、容器内边距、光线来源、接触阴影、透视和背景干扰。按实际存在的问题处理，无需为每页填写评分表。

先解决会改变结构的内容和主次问题，再调局部质感。例如标题没有结论、图表占比不符、三组内容关系混乱时，增加光效不会使页面变好。

## 把口语反馈转成可改的判断

| 用户反馈 | 先观察什么 | 可执行的修改 |
| --- | --- | --- |
| 太空、不够满 | 是主体太小、信息体量不足，还是各组距离过大 | 放大有意义的主体、加强重点与支撑内容的联系、收拢局部间距；内容确有缺口时建议补充证据 |
| 太挤、看不进去 | 是字量过多，还是分组和层级失效 | 重排信息层次、调整区块比例和组间距；必要时提议精简或拆页 |
| 不够高级 | 具体比较材质、字形、色彩、光影、主体比例与范例差异 | 指出一两处最有影响的差距并修改，避免只追加“高端、大气”等词 |
| 太花、太乱 | 是否多个焦点竞争，装饰比内容更亮 | 减少竞争焦点、降低背景细节和强调色面积 |
| 像贴上去的 | 光向、色温、地平线、透视、接触阴影是否一致 | 把主体和场景重新融图，统一光影与空间 |
| 没力量、重点不突出 | 主体是否过小，明暗和尺度差是否不足 | 扩大主体或关键结论，建立明显但有分寸的对比 |
| 太模板化 | 不同关系是否都被装进同一种盒子 | 根据对比、流程、层级或空间关系重组本页 |
| 字错了、只改标题 | 准确位置、原字和目标字是什么 | 使用当前成稿局部生图编辑，保留已认可的构图与其余文字 |

反馈模糊时先提出基于画面的诊断。例如：“当前空感主要来自主视觉太小和两组内容分散。我建议先把主体放大，并收拢内容组；背景配色保留。”让用户判断具体方案，而不是要求其学会设计术语。

## 选对修改层级

只需纠正局部文字、颜色或细节时，使用当前成稿作为编辑依据。内容位置与主次错误时，回到素稿调整。空间、主体或光源无法协调时，调整背景与主体后再成稿。方向整体改变时，先更新设计意图。

提示词中说明修改位置、目标状态与需要保留的部分。每轮保存新版本，实际查看结果后再选定。若相同改法持续无效，应更换构图或编辑策略；重复堆叠形容词不会让问题更清楚。

## 整套一起看

用总览比较标题气质、配色、正文层级、容器和图片处理是否属于同一套表达。检查信息密度的起伏、高潮页的位置、视觉焦点的变化、章节转场与结尾。参见 [叙事节奏](rhythm.md)。

同一套可以既有强视觉页又有饱满内容页。统一的是设计语言与表达目标，变化的是内容关系、焦点位置和节奏。不能因为某张内页没有封面那样炫目就把它判为不合格。

## 判断何时完成

页面的核心结论明确，信息真实完整，文字准确可读，视觉方向符合已对齐的范例偏好；主体、材质和排版没有明显破绽，整套能顺畅讲述，即可交付。若还有业务事实等待用户补齐，明确指出具体缺口，不把待补信息包装成已定稿内容。
