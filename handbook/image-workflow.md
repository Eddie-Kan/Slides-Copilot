# 生图工作法

用逐步明确的视觉依据，把内容、构图、材质和文字合成一张完整页面。每一步解决不同的设计问题，成稿继承前面已经成立的决定。

## 先写单页设计意图

先确定观众应当记住的结论、支持结论的内容关系，以及视线从哪里进入、到哪里结束。随后选择主视觉、内容区和页面填充程度。保留准确文案，把需要保留的名称、数字、单位和断行写清楚。

“右边放产品，左边放三条信息”只是位置描述；“以产品为主角，三条能力沿产品展开，观众先记住产品，再看到能力证据”才说明了构图为什么成立。内容适合流程、对比或空间关系时，应换用相应构图。

使用 [单页记录](../templates/page.md) 保存这些决定。模板是工作便笺，不要求为了填字段而发明信息。

## 背景图：先把舞台搭好

生成符合页面意图的无字背景。说明画幅、配色、亮暗分布、视角、主光、材质和需要保留的文字承载区。如果主体与环境不可分割，可以在这一步一起生成；如果需要准确产品外形，实际提供产品图片并说明其身份。

文字承载区可以有低对比纹理、色块、虚化环境和延伸线索，不等于挖一块生硬的空白。重要的是字放上去后能读清，主体仍然有力量。背景中的平台、道路、光束或建筑方向应为后续排版提供依据。

参考图确实有帮助时，先看图，再作为实际图像输入传给生图工具。仅在提示词里写一个路径，不等于模型已经收到了图片。背景可复用，但要检查新一页的内容区、光向和主体位置是否仍然适合。

## 排版素稿：让内容关系可见

素稿是一张可看的布局图，用来检验真实内容能否容纳、主次是否明确、页面是否达到期望的饱满程度。它可以简化材质和装饰，必须保留标题长度、正文行数、核心数字、图表轮廓和主体体量。

用背景作为参考生成素稿时，说明它只约束场景和大致空间；用准确文案或接近真实长度的文案呈现排版。需要非常快速比较位置时可以用块面，但块面不能代替最终对真实文案的容量检查。短短的“标题”“正文”占位字会掩盖装不下的问题。

检查阅读路径、分组、组内与组间间距、标题断行、主体遮挡和密度。需要调整时先改素稿。背景构图妨碍内容表达时，背景也一起调整。不要为了保住一张漂亮背景而牺牲文字。

## 完整成稿：合并已成立的依据

实际输入背景图与素稿，明确两者分工：背景规定空间、配色、光影和材质；素稿规定内容位置、比例和阅读关系。再给出完整准确文案，要求文字与画面一起生成。需要保真的产品、人物或标志图片可一并输入并说明作用。

提示词组织顺序建议为：页面用途与核心意图 → 每张参考图的职责 → 构图与填充度 → 材质、配色和字形 → 逐块准确文案 → 本页特别需要保持的细节。只写适用于本页的要求，避免堆叠互相竞争的风格形容词。

生成后实际打开结果。缩略图检查主次与整体力量，正常观看尺寸检查可读性，放大检查文字、细节、产品外形及数据。

## 文字也是成稿的一部分

以已确认文案为准逐字检查，特别注意近形字、专有名词、数字、小数点、单位、符号与遗漏。标题断行、中文标点和英文词组也要符合语义。图表中的数字、比例和标签应当相互对应。

发现错字时，以当前成稿为实际参考，通过生图编辑指定文字区域。提示词写清“位于哪里、现有文字是什么、应改成什么、需要保留什么”。必要时同时提供素稿帮助稳定布局。输出后再次核对该区域，并看整页是否出现连带变化。

长正文反复生成不稳定时，先定位问题：字太小、行太挤、纹理太复杂，还是同页信息过多。可以提高实际输出尺寸、增强文字承载区、改变断行或调整内容组织。涉及删减含义或拆页时，向用户提出具体建议。不要用代码或手工叠字绕过文字生成的工作方式。

## 样稿定调与连续制作

询问用户希望先看几页样稿，未指定时默认三页。选择最能验证设计难点的页面：可能是封面、最复杂的内容页和数据页，也可能是三张高密度内容页。用户已经选好页面时直接使用。

交给用户看的样稿应是完整页面，并简要说明本轮验证了什么、推荐哪种方向。通常在视觉方向、文案取舍或关键样稿处对齐；背景与素稿是内部制作步骤，用户想参与或关键分歧难以判断时再展示。

按约定由用户讨论选定，或由 Codex 自主选定方向，然后连续制作。把采用的配色、填充度、标题气质和主体处理方式简记在项目记录中。后续页面继承这些共性，每页重新思考内容关系与构图。单页特别精彩，但破坏整套调性时，应回到整套观看再取舍。

## 工具与记录

按当前生图工具的输入方式提供已查看的参考图片。背景与素稿生成完成后，将两张结果用于成稿。

把选定图片存入作品目录，随页保留对应提示词和参考文件，便于复用与改稿。
