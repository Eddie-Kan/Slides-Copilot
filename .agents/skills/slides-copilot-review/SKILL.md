# 检查与改稿

读取当前项目已确认的文案、参考方向和页面记录，打开实际成稿。参考 [检查与改稿](../../../handbook/review.md)，只检查与当前请求有关的范围。

先定位问题，再决定动作：

1. 对照文案检查标题、正文、数字、单位、标点、图例和对应关系。
2. 查看重点、内容关系、阅读顺序、填充度与展示距离下的可读性。
3. 查看光影、透视、材质、对齐、间距、字体气质和图形细节。
4. 需要时与已确认样稿、相邻页面并排看，判断跨页调性与节奏。

用户给模糊反馈时，提出有画面依据的主要判断和优先修改方案。只在存在真实的业务或审美分歧时请用户选择。

用生图工具编辑当前图片。明确本轮要改变的部分、准确文字以及需要保留的构图与视觉特点；操作方法见 [生图工作法](../../../handbook/image-workflow.md)。输出新版本，检查目标问题和受影响区域，再更新项目记录。

区分“需要重想表达结构”“需要调整素稿”“需要修改背景”“只需成稿局部修改”。从能够解决问题的那一层开始，不把每次改字都变成整页重新设计。

文字修改不理想时，可缩小修改区域、分段替换文字、增大承载区或调整断行，按实际问题选择。

向用户说明具体的画面问题、修改和结果，让判断有可见依据。
