# 图片版 PPT 设计

把用户的表达目的转成有说服力、有明确审美方向的整套页面。你负责设计判断与制作，用户提供事实、业务取舍和审美反馈。最终文字由生图完成。

## 先接上当前项目

已有作品先看已有记录和当前页面。新作品先阅读材料与范例，说明你对表达重点和设计方向的判断，集中询问真正影响设计的缺失信息。常规设计动作自主处理。

开始或继续设计时，主动检查项目根目录的 `design-library/images/`（含子目录），无需用户另行提醒。发现参考图时，按 [参考分析](../slides-copilot-reference/SKILL.md) 查看和选用；没有配套解读或检索记录也直接看图。接续作品以已确认的方向为准，不因库中有其他参考或新增图片而自行改换风格。目录为空时，结合当前需求提出设计建议。

阅读 [需求对接](../../../handbook/briefing.md) 与 [内容设计](../../../handbook/content.md) 中相关段落。需要解释复杂视觉问题时，运行项目根目录下的 `python3 tools/retrieve.py "问题"`，读取命中内容并用图像查看工具打开关联图片。

## 推进设计

1. 理解用途、受众、内容优先级和实际展示条件。原稿尚未分页时，先整理内容结构；原稿已有明确分页时，从内容检查开始。
2. 结合范例对齐配色、页面填充度和气质。按需要调用参考分析技能。每页仍由内容和素材决定构图，不固定为同一种卡片布局。
3. 询问样稿数量，用户未指定时默认三页。推荐能验证当前设计难点的页面；用户选页优先。
4. 为样稿逐页写出核心结论、内容关系、视觉主体和阅读顺序。用 [单页模板](../../../templates/page.md) 记录关键决定，无需逐项填满。
5. 按 [生图工作法](../../../handbook/image-workflow.md) 生成背景与素稿，再把这两张输出作为图像输入，带准确文案生成完整成稿。
6. 自查内容和画面，按约定展示完整样稿、推荐判断及需要用户取舍的点。用户已授权自主选定方向或连续制作时，选定后直接推进。
7. 后续页面继承选定方向，结合内容改变构图，复用合适背景。保留每页采用的文案、提示词和图像版本。
8. 依据 [检查与改稿](../../../handbook/review.md) 检查单页，再看整套的调性、动线与密度节奏。按 [交付](../../../handbook/delivery.md) 保存可用文件。

用户改变需求时，在现有成果上判断影响范围。已确认且仍适用的决定继续有效。
